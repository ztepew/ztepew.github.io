:: WHAT IS LINUX? ::

Linux is a free, open-source operating system kernel. Anyone can look at its code, change it, and share it. On top of that kernel, people build full operating systems called "distributions" — you install one of those, not "Linux" by itself.

:: WHO CREATED LINUX? ::

A Finnish student named Linus Torvalds started Linux in 1991 as a hobby project while studying at the University of Helsinki. He posted it online and asked for help — programmers around the world jumped in, and it grew into what powers servers, phones (Android), and countless devices today.

:: HOW TO INSTALL LINUX ::

  • Pick a distro (see the list below — Ubuntu or Mint are easiest for beginners).
  • Download the .iso file from the distro's official website.
  • Write it to a USB stick with a tool like Rufus or Balena Etcher.
  • Boot from the USB (usually F12 / F2 / Del at startup) and follow the installer.
  • Try "Try without installing" first if you're not sure yet!

:: HOW TO FIX COMMON ERRORS ::

  • Black screen on boot: try adding "nomodeset" to boot options.
  • No Wi-Fi: check if your card needs proprietary drivers (common on Broadcom cards).
  • "Command not found": you probably need to install that program first with your package manager.
  • System won't boot after update: boot into an older kernel from the GRUB menu.
  • When in doubt: read the error message carefully and search it — someone else has hit it too.
